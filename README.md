# HTML Character Generator

PSDから、立ち絵つきのHTML作品を作成できるブラウザツールです。

プログラムのインストールは必要ありません。ブラウザでPSDを読み込み、キャラクターのレイヤーと表情差分を選ぶだけで、作品一式をZIPファイルとして保存できます。

## アプリを開く

**[HTML Character Generatorを使う](https://komuhiyo56-dotcom.github.io/html-character-generator/)**

Google Chromeなどの新しいブラウザで開いてください。

## このツールでできること

- PSDのレイヤー構造を確認
- キャラクターとして動かすレイヤーを選択
- レイヤーの表示・非表示を使った表情差分の作成
- デフォルト状態と複数の差分プリセットの保存
- キャラクター全体への呼吸アニメーション
- 立ち絵つきHTML作品の書き出し
- PSDのレイヤー名とフォルダー階層を保った画像出力

キャラクターや背景を一枚の画像へ結合せず、PSDの各レイヤーを独立した透過WebP画像として出力します。表情差分は、表示するレイヤーの組み合わせとして保存されます。

## 使い方

### 1. PSDを読み込む

画面中央へPSDをドラッグ・アンド・ドロップするか、「PSDを読み込む」を押してファイルを選択します。

読み込みが終わると、左側にプレビュー、右側にレイヤー一覧が表示されます。

### 2. キャラクターを選択する

呼吸アニメーションを適用したいレイヤーの横にある選択欄を押します。

体、顔、髪、目、口、衣装など、キャラクターを構成するレイヤーをすべて選択してください。選択しなかったレイヤーは、背景や前景などの固定部分として扱われます。

選び終わったら「キャラクター選択を確定」を押します。

### 3. デフォルトを保存する

レイヤーの表示を切り替え、作品を開いたときに最初に表示したい状態を作ります。

状態が整ったら「デフォルトを保存」を押します。

### 4. 表情差分を作る

目や口などの表示を切り替えて別の表情を作り、分かりやすい名前を付けて「差分を保存」を押します。

例：

- 喜び
- 怒り
- 悲しみ
- 驚き
- 目閉じ

保存した差分は、一覧から選択・上書き・削除できます。

### 5. 呼吸を選ぶ

呼吸アニメーションは「なし」「控えめ」「標準」から選べます。

呼吸はキャラクター全体へまとめて適用されるため、レイヤー同士の位置はずれません。背景や前景などの固定部分には適用されません。

### 6. HTML作品を書き出す

「HTML作品を書き出す」を押すと、作品一式がZIPファイルとして保存されます。

ZIPファイルを展開し、中にある `index.html` をダブルクリックすると作品を再生できます。

## 出力された作品の操作

- 台詞ウインドウをクリック・タップ：次の台詞へ進む
- 立ち絵や背景部分をクリック・タップ：台詞ウインドウを非表示
- 台詞ウインドウが隠れている状態で画面をクリック・タップ：再表示

作品を開いた後にブラウザウインドウの大きさを変更しても、作品と台詞ウインドウは最初に表示された大きさを維持します。

## 台詞を変更する

出力フォルダー内の `scenario.js` を、メモ帳などのテキストエディターで開きます。

```js
{ preset: "デフォルト", text: "ここに台詞を書きます。" }
```

- `preset`：表示するプリセット名
- `text`：画面に表示する台詞

行を複製すると台詞を増やせます。引用符、波括弧、カンマを誤って消さないようにしてください。

## PSDを作るときのポイント

- レイヤーとフォルダーには分かりやすい名前を付ける
- 表情差分は、目や口などを別レイヤーにする
- キャラクターと背景・前景を別レイヤーにする
- 使用したい状態がPSD上でも正しく表示できることを確認する
- 調整レイヤーや特殊な合成効果を使ったPSDは、書き出し結果を必ず確認する

同名レイヤーがあっても内部では区別されますが、後から編集しやすくするため、できるだけ異なる名前を付けることをおすすめします。

## 画像について

- 元PSDの長辺が2000pxを超える場合、長辺2000pxまで縮小
- 長辺が2000px以下の場合は拡大しない
- すべてのレイヤーに同じ縮小率を使用
- 透過WebP、品質90で保存
- 元PSDの座標、重なり順、レイヤー名、フォルダー階層を維持

## プライバシー

読み込んだPSDは、お使いのブラウザ内だけで処理されます。

PSDや生成画像がGitHubなどの外部サーバーへ送信・保存されることはありません。ページを閉じると、編集中の内容は失われます。

## 注意事項

- 大きなPSDは、読み込みや書き出しに時間がかかる場合があります
- ブラウザのメモリ不足により、非常に大きなPSDを処理できない場合があります
- 一部の調整レイヤー、レイヤースタイル、特殊な合成モードは完全に再現できない場合があります
- 作業途中の状態は自動保存されません
- 書き出したZIPファイルは、必ず展開してから `index.html` を開いてください

うまく表示されない場合は、PSDを複製してから特殊効果を通常レイヤーへ変換し、もう一度お試しください。
