# HTML Character Generator

PSDを読み込み、イラスト制作者が迷わず立ち絵つきHTML作品を作るためのローカルWebアプリです。第6段階まで実装しています。

## GitHub Pagesで公開する

このプロジェクトには、GitHub Pages用の自動公開設定が含まれています。

1. GitHubで新しいリポジトリを作成し、このフォルダの内容を `main` ブランチへ送ります。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を `GitHub Actions` にします。
4. `Actions` で「GitHub Pagesへ公開」が完了するまで待ちます。
5. `Settings` → `Pages` に表示されたURLを開きます。

以後は `main` ブランチを更新するたびに自動で再公開されます。利用者側にNode.jsやpnpmは必要ありません。読み込んだPSDはブラウザ内で処理され、公開用サイトへ送信・保存されません。

## 起動方法

Node.js 22以降を用意し、次の順で実行します。

```text
pnpm install
pnpm dev
```

ブラウザで表示されたローカルURLを開き、PSDをドラッグ＆ドロップしてください。素材は外部へ送信されません。

## 推奨技術構成

- TypeScript + React：画面と状態を型安全に管理し、Electron化後もUIを再利用するため
- vinext / Vite：ローカル開発が速く、将来の配布形態を決める前にUIを検証しやすいため
- ag-psd：ブラウザ内でPSDの階層・日本語レイヤー名・画像データを解析できるため
- Canvas API：第2段階以降で固定部分とキャラクター部分を端末内合成するため
- Web Worker：第5段階で大きな画像処理をUIから分離するため
- JSZip（第6段階で追加予定）：生成したプレーンHTML一式をZIP保存するため

## ディレクトリと責務

```text
app/
├─ components/        UI（プレビュー、レイヤーツリー）
├─ lib/psd-reader.ts  PSD読み込み境界
├─ types/editor.ts    編集データの型
├─ page.tsx           画面の入口
└─ globals.css        見た目とレスポンシブ配置
```

今後は `lib/layer-state.ts`、`lib/image-composer.ts`、`lib/project-generator.ts`、`lib/file-saver.ts` を追加し、UI・PSD解析・画像処理・作品生成・保存を分離します。Electron化では `psd-reader` と `file-saver` の入出力アダプターを差し替え、React UIと編集データは維持します。

## データ構造

レイヤーは名前ではなく、読み込み時に階層位置から作る一意IDで識別します。同名や日本語名を安全に扱えます。グループは子を持つツリーで表し、表示状態と透明度を保持します。第2段階では選択したID集合をキャラクター、残りを固定表示として分離します。親グループ選択時は子IDへ展開し、重複を `Set` で除外します。

プリセットは次の形を予定しています。

```ts
type Preset = {
  id: string;
  name: string;
  visibleCharacterLayerIds: string[];
  isDefault: boolean;
};
```

## 第1～第6段階で実装した内容

- PSDのクリック選択とドラッグ＆ドロップ
- PSDの合成済みプレビュー
- グループを開閉できるレイヤーツリー
- 表示・非表示状態、透明度、日本語名、同名レイヤーの保持
- 特殊効果を検出した場合の日本語警告
- 読み込み失敗時も画面を保つ日本語エラー表示
- 添付図を整えた、プレビュー中心のPC／スマートフォン対応UI
- 進行状態に応じて内容が変わる固定案内欄の土台
- レイヤーまたはグループ単位でのキャラクター複数選択
- 親グループと子レイヤーの重複を避けた選択状態管理
- キャラクターと未選択の固定部分を分離したレイヤー別プレビュー
- レイヤー表示スイッチを即時反映するプレビュー
- キャラクター部分だけに適用する控えめな呼吸アニメーション
- キャラクター／固定部分／表示中レイヤーの件数表示
- 必須のデフォルトプリセット保存と上書き
- 差分プリセットの新規保存と一覧選択
- 保存したレイヤー表示状態のプレビュー復元
- プリセットの上書き保存と削除
- デフォルトプリセットの削除防止
- 空欄名と同名プリセットの日本語エラー表示
- 呼吸の「なし・控えめ・標準」切り替え
- 全プリセットで共通する呼吸設定
- 固定部分を含む全PSDレイヤーを個別の透過WebPとして出力
- `assets/layers/` 内へ元PSDのグループ階層と名前が分かる形で保存
- レイヤーごとの元PSD座標・サイズ・重なり順の保持
- プリセット画像を作らず、表示する一意レイヤーID一覧として分離
- 固定レイヤーをキャラクターの背面側・前面側へ分けて元の前後関係を維持
- 長辺2000px上限と、固定部分・キャラクター部分に共通する縮小率
- WebP品質90でのローカル変換
- 処理中の進捗表示
- `index.html`、`style.css`、`game.js`、`scenario.js` の生成
- 全プリセットを一度ずつ表示するサンプルシナリオ
- クリック・タップ・Enter・Spaceによるセリフ送り
- 最終セリフで停止する作品画面
- レイヤーID一覧によるプリセット切り替え
- 存在しないプリセット名の作品内警告
- 初心者向け `README.txt`
- 作品一式のZIPダウンロード

## 動作確認

1. 画面右下の「PSDを読み込む」を押す、または中央へPSDをドロップします。
2. プレビュー、画像サイズ、レイヤーツリー、日本語名を確認します。
3. グループを開閉し、各レイヤーの「表示」スイッチがプレビューへ反映されることを確認します。
4. レイヤー横の選択チェックボックスでレイヤーまたはグループを選び、選択部分だけが呼吸することを確認します。
5. 表示状態を整えて「デフォルトを保存」を押します。
6. 表示状態を変更し、名前を入力して差分を保存します。
7. プリセット一覧を選び、保存時の表示状態へ戻ることを確認します。
8. 上書き保存、削除と、同名・空欄時の案内を確認します。
9. 呼吸の3段階を切り替え、プリセットを変更しても設定が共通であることを確認します。
10. 「HTML作品を書き出す」を押し、ZIPを展開して `index.html` を開きます。
11. 全プリセットの切り替え、クリック・タップ、最終セリフでの停止を確認します。
12. `scenario.js` のセリフとプリセット名を編集して再確認します。
15. 非PSDを選び、日本語のエラーが表示されることを確認します。

## 現在の制限

- 調整レイヤー、レイヤースタイル、特殊描画モード、クリッピングマスクなどは完全再現できません。処理は止めず警告します。
- グループの不透明度や特殊な合成モードは、レイヤー別プレビューへ完全には反映されません。
- 非常に大きいPSDはブラウザのメモリ上限に達する可能性があります。
- PSDに埋め込まれた合成画像がない場合、現在はプレビューを作れません。
- ブラウザ差や特殊PSD仕様を推測で補完しません。

## UI図と仕様の整理

添付図ではレイヤーの丸印が「表示」と「キャラクター選択」の両方に見えるため、誤操作を避ける目的で今後は別々の操作にします。表示は目印スイッチ、キャラクター選択はチェック欄として分離します。また、案内欄は右下へ固定しつつ、狭い画面では下端へ追従します。
